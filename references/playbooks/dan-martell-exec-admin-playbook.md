# Reference — Dan Martell: "Exec Admin Playbook"

**Source:** Dan Martell Elite Coaching SOP, provided by Gina 2026-07-04.
**What it is:** The operating manual for a human executive assistant. This is the **"brain" layer** in our two-layer model (see [[hub-design-playbooks]]) — the principles, cadence, SOPs, and templates that the Claude Code EA / second-brain build will hold, and that the Hub flows execute.
**Skip:** the founder-with-human-EA scaffolding that's out of scope for a church-operations role — travel booking, house manager, gift buying, 1Password admin, podcast-day scheduling.

## North Star Principles (→ EA CLAUDE.md operating principles)
- **Protect the principal's time** — filter inbound, surface only what's important.
- **Efficiency in calendar** — clear, committed, with context.
- **Appreciate the response** — every message gets a clear, kind reply, whether a "yes + details" or a "not at this time."
- **Design the play** — be preemptive; come prepared, aware of the moving pieces.
- **Prioritize revenue** — order tasks by biggest outcome; make/save money first.

## Inbox processing (→ directly shapes the Hub)
- **Cadence:** process the inbox **twice a day**, target inbox-zero by ~10 AM and again by ~5 PM. → Sets Watchdog to **two digest passes/day**.
- **Response SLAs** (his template leaves the day-counts as `X` — Gina to set real numbers): initial-response target · resolution target · online-order · payment-owed. → These become **Tempo's follow-up windows** (tighter clock for High than FYI).
- Rules for keeping the inbox clean + labeling rules → map to Sweep (folder moves) + Steward (disposition).

## Response templates (→ Courier's draft-template library, rewritten in FBCG/Gina voice — never "Dan's assistant")
Base "reply on their behalf" opener: *"This is [Name], [Principal]'s assistant. I got to your email before they did and thought you'd appreciate a speedy reply…"* Then the specific close:
- **Pass on an investment/opportunity** — thank them, decline politely ("heads down, not taking new items outside immediate network"), wish them well.
- **Pass on an event invitation** — thank them, decline ("not available at this time"), wish the event well.
- **Pass on a writing/blog collaboration** — thank them, decline ("not co-collaborating at this time"), encourage them.

## Task cadence (→ candidate EA skills)
- **Daily:** review calendar for the day; process inbox to zero (2×); process own inbox; schedule requested calls; build/close a daily to-do; prep for principal meeting; EOD sweep (answer lingering items, leave notes on tomorrow's items, build next-day list).
- **Weekly:** audit calendar 6 weeks out; confirm invites accepted; review commitments.
- **Monthly / Quarterly / Annually:** (template placeholders — define per role.)

## Admin Meeting agenda (8 parts, → an EA skill/template)
Title → Meeting Action Items (meetings since last sync) → Calendar review → Previous meetings (any follow-up?) → Principal's agenda → Closing the loop (what's resolved) → Assistant to review (challenging emails/opportunities) → Projects (in priority order, **offer 3 resolution options per problem**) → Questions for the principal.
Meeting cadence ramps: daily at first → 3×/week after 4–6 weeks → weekly after 3 months.
